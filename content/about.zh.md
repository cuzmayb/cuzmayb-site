# 你好，我是 Hyojun Jung。

我是汉阳大学 ERICA 材料化学工程系四年级学生，预计 2027 年 2 月毕业，GPA 为 <span class="nw">4.05/4.5</span>。

我想从薄膜、刻蚀、布线这些材料与工艺的角度，解决半导体先进封装中出现的问题。现在正在做用 Python 和 AI 工具处理工艺问题的项目。

我最好奇的是，一个工艺条件如何改变封装和系统层面的质量。我一边补足这份工作所需的能力，一边在这里记下在哪里卡住、为什么那样判断、学到了什么。

## cuzmayb 这个名字

取自 Oasis 的《Wonderwall》歌词中的 "because, maybe"。cuz 是 because 的缩写。

像 2026 年世界杯上的贝林厄姆一样，我想成为在卡住时给出答案的人。

## 最近在想的事

### 用几个试样定下的工艺窗口，量产时还对吗？

在实验室里，工艺条件的极限是用几个试样定下来的。这份余量能否覆盖数量增加后的波动，需要另外确认。我在思考，要让少量实验得出的窗口可信，应该先看哪些失效模式。

### 仿真结果要怎样在实物上确认？

仿真只在它假设的数值范围内给出答案。如果实际产品的波动比假设更大，计算得到的检出极限或工艺窗口就不会原样成立。我想知道要在实物上测什么、测多少，模型才可信。

### 我喜欢什么，又不知道什么？

在决定做什么工作之前，我想先看清自己喜欢什么、知道什么、不知道什么。这也是我在每个项目里都记下卡住之处的原因。
