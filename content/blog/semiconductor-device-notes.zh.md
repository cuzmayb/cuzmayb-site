## 先说结论

C-V 曲线保持形状不变向一侧平移，是氧化层中的固定电荷造成的；斜率变缓、曲线被拉伸，是 Si-SiO₂ 界面态造成的。闪存把前一种现象用于存储。

## 基准线

V_fb = Φ_ms − Q_ox/C_ox，1/C_g = 1/C_ox + 1/C_si。数值随 Si 一侧的状态而变化。

| 区间 (p-type) | C_g |
|---|---|
| Accumulation | C_ox |
| Depletion | 减小 |
| 高频 inversion | 保持 C_min |
| 低频 inversion | 恢复到 C_ox |

## 平移：固定电荷

氧化过程中在界面附近形成的 SiO_x 缺氧，带正电荷。存在这种电荷时，整条曲线移动 ΔV = −Q_ox/C_ox。正电荷向负电压方向移动，负电荷向正电压方向移动。由于电荷是固定的，形状保持不变。

## 拉伸：界面态

界面处的 dangling bond 在禁带中形成能级。V_g < 0 时，空着的 state 表现为正电荷，使曲线向 −V 方向移动；V_g > 0 时被填满成为负电荷，使曲线向 +V 方向移动。方向随电压相反，所以曲线被拉伸。Dangling bond 密度为 (100) < (110) < (111)，因此使用 (100) 晶圆。

## 闪存有意制造平移

向浮栅注入电子后，按照与 oxide trapped charge 相同的原理，C-V 向正方向平移，阈值升高 ΔV_T。在两种状态之间的读取电压下，erased 状态有电流流过，written 状态没有。ΔV_T 要足够大，两者才能明确区分。

这一单元里最清楚的一点是，缺陷和存储器工作可以用 ΔV = −Q_ox/C_ox 这一个式子联系起来。
