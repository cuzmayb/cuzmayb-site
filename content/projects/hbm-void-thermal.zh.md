> 本文的数据是用仿真生成的合成数据，没有对堆叠芯片的实测值。

## 问题

HBM 用键合层把 12 片 DRAM 堆叠起来。手算发现，仅键合层导热系数这一项，就能让堆叠温差从 0.5 K 变到 137 K。键合层里出现空洞（void），热就被挡住。我想知道，能否不切开芯片，只凭上电后温度上升的曲线 Zth(t) 找到空洞。

1. 从多少 % 的空洞开始能检出？
2. 能否定位到是第几层？
3. 决定这个极限的是什么？

## 我的判断与依据

### 方法

| 步骤 | 内容 |
|---|---|
| 模型 | 12 层堆叠 1D RC 梯形网络（每层分 10 段）。面积 112.4 mm²，键合层厚 15 µm，导热系数 0.5 W/m·K。与解析解的偏差在 1 % 以内，与手算表按 2 % 容差对齐 |
| 正向 | 在结区施加 1 W 阶跃输入 → Zth(t) |
| 逆向 | Zth → 时间常数谱 → Cauer 电路 → 结构函数 |
| 缺陷 | 把某一层键合层按面积比例切断导热。这是对分散小空洞的近似 |
| 检测 | 超过 300 个良品分布的 99 % 分位数即判为不良 |
| 定位 | 将不良品与良品平均值之差拟合到 12 层 × 空洞尺寸模板 |
| 外部验证 | 将 IBM 文献（Smith 2007）的条件和实测曲线输入同一流程进行比较 |

### 把判定标准从 3σ 改为 99 % 分位数

起初以超过良品平均值 3σ 为不良。在只读文件、不给背景的独立评审中，有人指出这个标准的实际误报率是 2.15 %。原因是良品的总热阻分布向一侧偏斜。于是把标准改为 300 个良品的 99 % 分位数，并用 2000 个新的良品重新测了误报率。噪声为 0.01、0.1、1 % 时分别是 1.25、0.95、3.0 %。

### 把键合层输入换成实测范围后重算

最初输入的键合层面热阻 30 mm²·K/W，是用文献中胶膜（NCF）的物性算出来的。查了量产工艺和实测论文后发现，µbump 加底部填充层的实测值是 4.2 ~ 19 mm²·K/W，hybrid bonding 是 0.80 ~ 1.28 mm²·K/W。输入比实测大 1.6 到 7 倍。我只改键合层的数值，把同一流程重新跑了一遍，结果就是下面「按键合工艺」的表。

### 找到了 2D 模板不如 1D 的原因

聚成一团的空洞无法用 1D 求解，所以另做了 2D 轴对称模型。把 1D 模板拟合到 2D 生成的数据上，µbump 堆叠的第 6 层和第 9 层 ±1 层准确率只有 48 %。随后做了 2D 模板，起初反而不如 1D。原因有两个。尺寸网格太粗，形状不对的模板只因幅值凑巧吻合而胜出。良品基准曲线取自另一套网格，这个差异（0.02 ~ 0.08 %）和空洞信号一样大。两处改掉以后，同样的层达到 98 % 以上。

### 把适用范围收窄到测试芯片阶段

HBM 规范（JESD235D）的内置温度传感器以 1 ℃ 为单位输出。本方法假设的噪声 0.1 %，在加热 1 W 时约为 3.7 mK，内置传感器达不到这个水平。所以把适用范围限定在使用热测试芯片的工艺开发阶段。它不适合量产产品的现场诊断。

## 结果

### 无离散时

测量噪声不超过最终 Zth 的 0.1 % 时，面积 2.5 % 的空洞起，12 层全部检出率达 90 % 以上。位置从面积 10.5 % 起，12 层全部能以 90 % 以上的比例定位到 ±1 层以内。5.5 % 时随层不同为 75 ~ 100 %。噪声增大到 1 % 时，检测从 20.5 % 起，定位从 50.5 % 起。

![检出率与定位准确率随空洞面积变化的曲线](/images/hbm-void-detection.webp "检出率（左）与 ±1 层定位准确率（右）随空洞面积的变化。取 12 层中的最低值，良品离散为 0。合成数据，由 thermal-stack 结果文件 w3_void.csv 绘制。")

### 良品有离散时

如果各层键合导热系数各自独立地离散 j，90 % 检出所需的空洞面积 φ 按 φ/(1−φ) = (3 + 1.28)·j·√12 增大。在这些面积上，蒙特卡洛检出率为 82 ~ 100 %。

| 各层离散 j | 90 % 检出所需面积 | 最上层（第 12 层）±1 层定位 |
|---|---|---|
| 0 | 2.5 % | 10.5 % 起 90 % 以上 |
| 1 % | 12.9 % | 25.5 % 时 92 % |
| 2 % | 22.9 % | 40.5 % 时 90 % |
| 5 % | 42.6 % | 50.5 % 时也只有 78 % |

![不同层间离散下的检出率曲线](/images/hbm-void-spread.webp "各层键合导热系数离散为 0、1、2、5 % 时的检出率。噪声 0.1 %，取第 1、3、6、9、12 层中的最低值。合成数据，由 w3_void.csv 和 w3_robust.csv 绘制。")

只要有 1 % 的离散，检测极限就从 2.5 % 退到约 13 %。此时决定极限的是良品离散性。不过这句话只在测量噪声不超过 0.1 %、温度灵敏度（K-factor）标定误差不超过 0.1 %、冷却端重复性不超过 1 % 时成立。噪声为 1 % 时，噪声造成的热阻波动（0.012 K/W）比 1 % 离散造成的波动（0.009 K/W）更大。标定误差和冷却端重新安装的误差只做了换算，没有仿真。

### 结构函数与各层的危害

- 结构函数只显示第一个键合层的边界。从结区看，时间常数为 0.19 s 的单个极点占总热阻 3.73 K/W 中的 3.16 K/W（85 %），一层键合层只占 7 %。这是从采样曲线估计谱这一步的局限，输入精确值时 12 层全部可以恢复。
- 越靠上的层通过的热量越多，同样的空洞危害也越大。面积 50 % 的空洞在第 1 层使结温升高 1.60 K，在第 12 层升高 7.47 K（工作功率 30 W）。结构函数显示的是危害最小的第 1 层，有离散时靠上的层最先丢失位置。

### 按键合工艺

离散为 0、噪声 0.1 % 时，只改变键合层面热阻的结果。

| 键合层 | 面热阻 (mm²·K/W) | 90 % 检出面积 | 该空洞造成的结温升高（最上层） |
|---|---|---|---|
| 均质 NCF 假设（最初输入） | 30 | 2.5 % | +0.19 K |
| µbump + 底部填充，实测 | 19 ~ 8.0 | 2.5 % | +0.12 ~ 0.05 K |
| µbump + 底部填充，40 µm 节距 | 4.2 | 5.5 % | +0.06 K |
| hybrid bonding | 1.28 ~ 0.80 | 5.5 ~ 10.5 % | +0.02 K |

- 键合层越好，分散的空洞越难看到，但其危害下降得比这更快。
- 聚成一团的空洞则不同。在最上层中心放一个面积 3 % 的圆形空洞并用 2D 求解，结区最高温度升高 0.85 ~ 1.23 K。同样面积分散开时是 0.006 ~ 0.23 K。
- 把 2D 生成的数据输入同一算法，面积 1 % 的单个团状空洞仍有 95 ~ 100 % 被检出（离散为 0）。

### 一组外部实测

从 Smith 2007（IBM）的 Fig. 2 中读取了 3 条实测瞬态响应曲线（TIM 厚度 4.2、23.7、34.2 µm），输入同一流程。从 23.7 µm 与 4.2 µm 两条曲线之差，把增加的热阻读为 TIM 层 0.0387 K·cm²/W。真值是 0.0406，误差 −5 %。包含 34.2 µm 的两组分别少读了 15 % 和 33 %。

## 局限与下一步

- 数据是合成的。实测只有一组单芯片加 TIM 试样的文献曲线，没有测过堆叠芯片。
- 1D 模型假设空洞周围的横向热扩散是充分的。这对大的单个空洞偏乐观，所以另用 2D 轴对称求解。偏离中心的空洞和多个空洞需要 3D。
- 假设加热点和测温点相同。实际加热元件和温度传感器的位置、分辨率不在模型里。
- 键合层面热阻是测试堆叠的实测值，没有 HBM 产品的数值。NCF 的热容没有出处，用底部填充的数值代替。
- 良品离散性的实际大小和允许温度，在文献中没有找到。因此不做判定，只作为变量给出。
- 下一步：在模板中加入 TIM 和冷却端的项，看冷却端重新安装的离散与最上层空洞能否按时间常数区分。程序已经可以直接读入时间和 Zth 两列的实测曲线。
