> 이 글의 데이터는 시뮬레이션으로 만든 합성 데이터다. 적층 다이를 실제로 잰 값은 없다.

## 문제

HBM은 DRAM 12장을 본딩층으로 쌓는다. 손계산을 해 보니 본딩층 열전도도 하나가 스택 온도차를 0.5 K에서 137 K까지 바꿨다. 본딩층에 void(빈 곳)가 생기면 열이 막힌다. 칩을 자르지 않고, 전원을 켠 뒤 온도가 오르는 곡선 Zth(t)만으로 void를 찾을 수 있는지 알고 싶었다.

1. 몇 % void부터 검출되는가.
2. 몇 번째 층인지까지 알 수 있는가.
3. 그 한계를 정하는 것은 무엇인가.

## 내가 한 판단과 근거

### 방법

| 단계 | 내용 |
|---|---|
| 모델 | 12단 스택 1D RC 사다리(층당 10분할). 면적 112.4 mm², 본딩층 두께 15 µm, 열전도도 0.5 W/m·K. 해석해와는 1 % 안에서, 손계산 표와는 허용오차 2 %로 맞췄다 |
| 순방향 | 접합에 1 W 계단 입력 → Zth(t) |
| 역방향 | Zth → 시상수 스펙트럼 → Cauer 회로 → 구조함수 |
| 결함 | 본딩층 한 층에서 면적 비율만큼 열전도가 끊긴 것으로 둔다. 흩어진 작은 void의 근사다 |
| 검출 | 양품 300개 분포의 99 % 분위수를 넘으면 불량 |
| 위치 | 불량과 양품 평균의 차이를 12층 × void 크기 템플릿에 맞춤 |
| 외부 검증 | IBM 문헌(Smith 2007) 조건과 실측 곡선을 같은 파이프라인에 넣어 비교 |

### 판정 기준을 3σ에서 99 % 분위수로 바꿨다

처음에는 양품 평균에서 3σ를 넘으면 불량으로 봤다. 맥락 없이 파일만 읽게 한 독립 리뷰에서 이 기준의 오경보가 실제로는 2.15 %라는 지적이 나왔다. 양품의 열저항 합 분포가 한쪽으로 치우쳐 있었다. 기준을 양품 300개의 99 % 분위수로 바꾸고, 새 양품 2000개로 오경보율을 다시 쟀다. 노이즈 0.01, 0.1, 1 %에서 각각 1.25, 0.95, 3.0 %였다.

### 본딩층 입력을 실측 범위로 바꿔 다시 돌렸다

처음 넣은 본딩층 면저항 30 mm²·K/W는 문헌의 접착 필름(NCF) 물성에서 계산한 값이었다. 양산 공정과 실측 논문을 찾아보니 µbump와 언더필 층의 실측은 4.2 ~ 19 mm²·K/W, hybrid bonding은 0.80 ~ 1.28 mm²·K/W였다. 입력이 실측보다 1.6배에서 7배 컸다. 본딩층 값만 바꿔 같은 파이프라인을 다시 돌렸고, 그 결과가 아래 「본딩 공정별」 표다.

### 2D 템플릿이 1D보다 못 맞힌 원인을 찾았다

한 덩어리로 뭉친 void는 1D로 풀 수 없어 2D 축대칭 모델을 따로 만들었다. 2D가 만든 데이터에 1D 템플릿을 맞추면 µbump 스택의 6층과 9층에서 ±1층 정확도가 48 %였다. 2D 템플릿을 만들어 넣었는데 처음에는 1D보다 못 맞혔다. 원인은 두 가지였다. 크기 격자가 성겨서 모양이 틀린 템플릿이 진폭만 맞아 이겼다. 양품 기준 곡선을 다른 격자에서 가져와 그 차이(0.02 ~ 0.08 %)가 void 신호만큼 컸다. 둘을 고치자 같은 층에서 98 % 이상이 됐다.

### 적용 범위를 시험 칩 단계로 좁혔다

HBM 규격(JESD235D)의 내장 온도 센서는 1 ℃ 단위 값을 낸다. 이 방법이 가정한 노이즈 0.1 %는 가열 1 W에서 약 3.7 mK다. 내장 센서로는 낼 수 없는 수준이다. 그래서 적용 범위를 열 시험 칩을 쓰는 공정 개발 단계로 한정했다. 양산 제품의 현장 진단에는 맞지 않는다.

## 결과

### 산포가 없을 때

측정 노이즈가 최종 Zth의 0.1 % 이하이면 면적 2.5 % void부터 12층 모두에서 90 % 이상 검출한다. 위치는 면적 10.5 %부터 12층 모두 ±1층 안에서 90 % 이상 맞는다. 5.5 %에서는 층에 따라 75 ~ 100 %다. 노이즈가 1 %로 커지면 검출은 20.5 %부터, 위치는 50.5 %부터다.

![void 면적에 따른 검출률과 위치 정확도 그래프](/images/hbm-void-detection.webp "void 면적에 따른 검출률(왼쪽)과 ±1층 위치 정확도(오른쪽). 12층 중 가장 낮은 값이고 양품 산포는 0이다. 합성 데이터, thermal-stack 결과 파일 w3_void.csv로 그렸다.")

### 양품 산포가 있을 때

층마다 본딩 열전도도가 독립으로 j만큼 흩어지면 90 % 검출에 필요한 void 면적 φ는 φ/(1−φ) = (3 + 1.28)·j·√12 로 커진다. 이 면적에서 몬테카를로 검출률은 82 ~ 100 %였다.

| 층별 산포 j | 90 % 검출에 필요한 면적 | 맨 위층(12층) 위치 ±1층 |
|---|---|---|
| 0 | 2.5 % | 10.5 %부터 90 % 이상 |
| 1 % | 12.9 % | 25.5 %에서 92 % |
| 2 % | 22.9 % | 40.5 %에서 90 % |
| 5 % | 42.6 % | 50.5 %에서도 78 % |

![층별 본딩 열전도도 산포에 따른 검출률 그래프](/images/hbm-void-spread.webp "층별 본딩 열전도도 산포 0, 1, 2, 5 %에서의 검출률. 노이즈 0.1 %, 1·3·6·9·12층 중 가장 낮은 값. 합성 데이터, w3_void.csv와 w3_robust.csv로 그렸다.")

산포가 1 %만 있어도 검출 한계는 2.5 %에서 약 13 %로 물러난다. 이때 한계를 정하는 것은 양품 산포다. 단 이 말은 측정 노이즈 0.1 % 이하, 온도 감도(K-factor) 교정 오차 0.1 % 이하, 냉각단 재현성 1 % 이하일 때만 맞다. 노이즈가 1 %이면 노이즈가 만드는 열저항 흔들림(0.012 K/W)이 산포 1 %의 흔들림(0.009 K/W)보다 크다. 교정 오차와 냉각단 재장착 오차는 계산으로 환산만 했고 시뮬레이션하지 않았다.

### 구조함수와 층별 해로움

- 구조함수는 첫 본딩층 경계만 보여준다. 접합에서 본 응답은 시상수 0.19 s인 극점 하나가 전체 열저항 3.73 K/W 중 3.16 K/W(85 %)를 차지하고, 본딩층 하나는 7 %다. 샘플링한 곡선에서 스펙트럼을 추정하는 단계의 한계이고, 정확한 입력을 넣으면 12층이 모두 복원된다.
- 위층일수록 지나는 열이 많아 같은 void도 더 해롭다. 면적 50 % void는 1층에 있으면 접합 온도를 1.60 K, 12층에 있으면 7.47 K 올린다(동작 30 W). 구조함수가 보여주는 층은 가장 덜 해로운 1층이고, 산포가 있으면 위층부터 위치를 잃는다.

### 본딩 공정별

산포 0, 노이즈 0.1 %에서 본딩층 면저항만 바꾼 결과다.

| 본딩층 | 면저항 (mm²·K/W) | 90 % 검출 면적 | 그 void의 접합 온도 상승 (맨 위층) |
|---|---|---|---|
| 균질 NCF 가정 (처음 입력) | 30 | 2.5 % | +0.19 K |
| µbump + 언더필 실측 | 19 ~ 8.0 | 2.5 % | +0.12 ~ 0.05 K |
| µbump + 언더필, 40 µm 피치 | 4.2 | 5.5 % | +0.06 K |
| hybrid bonding | 1.28 ~ 0.80 | 5.5 ~ 10.5 % | +0.02 K |

- 본딩층이 좋아지면 흩어진 void는 덜 보이지만 그보다 빨리 덜 해로워진다.
- 한 덩어리 void는 다르다. 맨 위층 중심에 면적 3 %인 원형 void를 두고 2D로 풀면 접합 최고 온도가 0.85 ~ 1.23 K 오른다. 같은 면적이 흩어져 있을 때는 0.006 ~ 0.23 K다.
- 2D가 만든 데이터를 같은 알고리즘에 넣어도 면적 1 %인 한 덩어리 void를 95 ~ 100 % 검출했다(산포 0).

### 외부 실측 한 건

Smith 2007(IBM)의 Fig. 2에 있는 실측 과도 응답 3개(TIM 두께 4.2, 23.7, 34.2 µm)를 그림에서 읽어 같은 파이프라인에 넣었다. 23.7 µm와 4.2 µm 두 곡선의 차이에서 늘어난 저항을 TIM 층 0.0387 K·cm²/W로 읽었다. 정답은 0.0406이고 오차는 −5 %다. 34.2 µm가 낀 두 쌍은 15 %, 33 % 작게 읽었다.

## 한계와 다음 단계

- 합성 데이터다. 실측은 단일 칩과 TIM 시편의 문헌 곡선 한 건이고, 적층 다이를 잰 것은 없다.
- 1D 모델은 void 주변의 측면 열 확산이 완전하다고 본다. 큰 단일 void에는 낙관적이라 2D 축대칭으로 따로 풀었다. 중심에서 벗어난 void와 여러 개의 void는 3D가 필요하다.
- 가열점과 센서점이 같다고 가정했다. 실제 가열 소자와 온도 센서의 위치, 분해능은 모델에 없다.
- 본딩층 면저항은 시험 스택의 실측이고 HBM 제품 값은 없다. NCF의 열용량은 출처가 없어 언더필 값으로 대신했다.
- 양품 산포의 실제 크기와 허용 온도는 문헌에서 찾지 못했다. 그래서 판정하지 않고 변수로만 제시했다.
- 다음 단계: 템플릿에 TIM과 냉각단 항을 넣어, 냉각단 재장착 산포와 맨 위층 void가 시정수로 갈리는지 본다. 실측 곡선이 생기면 시간과 Zth 두 열로 바로 넣을 수 있게 해 두었다.
